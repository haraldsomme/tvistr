# New app (artifact flow) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace every page with a React port of the externally built «Bilreklamasjon» artifact (named Tvistr), keeping Tvistr's ranking, decision choice and data pipeline.

**Architecture:** Pure, client-safe logic ported from the artifact lives in `src/lib/app/` (dates, law-version rules, `evaluate`, the letter, the mapping to `byggSaken`). Three routes: `/` (landing, static), `/sak` (check + verdict, client), `/brev` (writer, client, unlocked only). Two server actions talk to the database: `vurderSaken` (counts + 3 cards, no model) and `finnVedtak` (ranking + one Sonnet call → 3 sealed-by-payment paragraphs). State lives in `localStorage`.

**Tech Stack:** Next.js 16 (read `node_modules/next/dist/docs/` before writing routing/server-action code, per AGENTS.md), React 19, TypeScript, Vitest, Playwright, Drizzle/Neon.

**Spec:** `docs/superpowers/specs/2026-10-16-ny-app-design.md`. The artifact source: `~/.claude/projects/-Users-harald-somme-dev-tvistr/61c97f80-b9d6-4707-9bf7-311314b87b9d/tool-results/artifact-f0db5523-1792176885-2900.html` (if gone, `Artifact` tool `read` on https://claude.ai/artifact/Wk3A7KViL3Dnjr2qAPfENK). Line numbers below refer to that file.

## Global Constraints

- The UI must not drift from the artifact: same copy, layout and interactions, except the name (Tvistr) and used-cars-only. Where artifact and spec disagree, the spec wins.
- Every «Bilreklamasjon» becomes «Tvistr». «kr [PRIS]» becomes `kr ${tall(PRIS)}` from `src/lib/pris.ts`.
- Used cars only: no «Ny eller brukt» question, no «Ny bil» tile; the case is always `brukt`. Kjøpsloven branches (`isF()` false) are removed.
- Law version: `lovversjon(c_purchase || c_delivery)` from `src/lib/brev/paragrafer.ts` (check: `lovversjon(delivery)`). `før_2024`: presumption 6 months, «som den er» under old § 17 første ledd bokstav a with `LOVORD.dårligereStand`. `etter_2024`: the artifact's wording (2 years, `§ 15 annet ledd`). Paragraph numbers come from `PARAGRAFER`, months from `FORMODNING_MND` (`src/lib/brev/tidslinje.ts`).
- No quote from a decision and no `kilde_url` reaches the browser before payment. Case number, year, car and outcome may.
- No sentence in the decision section that is not from the database or `mal.ts`.
- Fault categories are `HOVEDKATEGORIER` from `src/lib/feil/kategorier.ts` (area = `hoved`, observed issues = `under`).
- Storage: `localStorage`, keys `tvistr-sjekk`, `tvistr-skjema`, `tvistr-ordre`; every read/write in try/catch; a missing or corrupt value gives the defaults.
- Fonts: Geist, Geist Mono, Source Serif 4, Barlow Condensed (600) via `next/font/google`; the artifact's CSS tokens (`--accent:#1F4F8F` etc.) unchanged.
- Code comments in English, UI copy in Norwegian, names in the repo's Norwegian style.

## Review Focus

1. A stale or corrupt `localStorage` value (old artifact draft, edited JSON) → the page loads with defaults, no crash. → Task 6 (`lagring.test.ts`).
2. Purchase date on the boundary (2023-12-31 vs 2024-01-01) → the law version flips exactly there in both verdict and letter. → Tasks 2 and 3.
3. Dates out of order or missing (found before handover, future date, only one date) → verdict shows «Sjekk at datoene stemmer»/«Datoene mangler», letter shows placeholders, nothing throws. → Tasks 2 and 3.
4. Fewer than 3 candidates, none, or the model call failing → `finnVedtak` returns 1–2 options, or `LOVSETNING` with no picker, or the ranking's fallback. → Task 5.
5. An unpaid or forged order id → `finnVedtak` returns an error with no `avsnitt`/`kildeUrl`; opening `/brev` unpaid redirects to `/sak`. → Tasks 5, 8 and 10.
